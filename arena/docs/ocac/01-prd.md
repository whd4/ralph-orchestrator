# OCAC Product Requirements Document

> **Product**: OpenClaw Agentic Companion (OCAC)
> **Tagline**: "The world's first personal cognitive twin"
> **Version**: 1.0

---

## Vision

OCAC is a personal cognitive twin — an AI companion that learns your behavior, predicts outcomes, and acts as your autonomous proxy. It's not a chatbot. It's not a tool. It becomes a recognizable "someone" who knows you deeply.

Two tiers:
- **Personal Tier**: Individual cognitive twin (Phase 1)
- **Enterprise Tier**: Organizational intelligence layer (Phase 2)

## Roadmap

### Phase 1: Personal MVP (0-2 months)
- Onboarding flow (conversational identity mapping)
- Behavioral Memory Architecture
- Deep Confidence Engine
- Monte Carlo Prediction Engine
- Character/Personality Engine v1

### Phase 2: Enterprise MVP (2-4 months)
- Organizational memory graph
- Team-level Monte Carlo forecasting
- Integration layer (Slack, Calendar, CRM)
- BMAD governance layer (auditability, compliance)

### Phase 3: Global Scale (4-6 months)
- Multi-device sync
- Advanced analytics dashboard
- Subscription management
- Data marketplace

---

## Privacy Requirements (Non-Negotiable)

- Local-first memory storage
- Encrypted personal state (at rest and in transit)
- User-controlled data ingestion (explicit opt-in for every source)
- No cross-user training
- No shared models between users
- No medical/mental health claims
- No diagnoses, no therapy
- User can export or delete ALL their data at any time
